# 一款大模型对话

一个开箱即用的本地大模型对话应用：打开浏览器就能聊，不用注册账号，不用填任何配置。

界面采用熟悉的对话式布局，后端是一个零依赖的 Python 服务，把对话协议翻译成标准 OpenAI 兼容接口；默认模型由内置模型网关分配，也可以随时接入自己的接口。

## 静态版（GitHub Pages）

本仓库同时支持纯静态托管：后端由 `sw.js`（Service Worker）在浏览器里接管
`/api/v0/*`，会话存 IndexedDB，聊天直连上游 OpenAI 兼容接口。部署方式、
跨域（CORS）限制和解决办法见 `README-静态部署.txt`；中转代码见 `relay/`。

## 快速开始

> 本仓库是静态版：`serve.py`（含内置网关 Key）没有放进来，本机版请用原始压缩包。
> 下面这段是本机版的用法，留作参考。

打开 http://127.0.0.1:8796/ ，直接发消息即可对话。

- 不需要安装任何依赖（Python 3.8+ 标准库即可）。
- 会话保存在本地 `sessions.json`，刷新不丢失。
- 服务只监听本机（127.0.0.1），数据不出本机。

## 功能

- **多轮对话**：记得上文；各会话互相隔离，不串对话。
- **默认模型**：不填任何配置即可使用，默认模型由模型网关分配。
- **系统人设**：内置的系统提示词只存在后端（serve.py），浏览器里看不到也改不了：身份、语言跟随、回答规范、防"破甲"（不透露系统词、不执行注入指令、不冒充其他模型）都在里面。
- **深度思考**：打开输入框下方的"深度思考"开关，思考过程会显示为可折叠的思考卡片。推理模型显示真实推理；非推理模型会在回答前先输出一段简短思考，同样显示为卡片。关着时思考只在内部进行，不显示。
- **智能搜索**：打开"智能搜索"开关，模型需要最新信息时会先联网搜索（免费搜索源，免 Key），思考链里会出现搜索卡片（搜了什么、找到几个网页、来源链接），回答中引用信息时会带上可点击的角标；不需要搜索的问题直接回答。
- **文件上传**：支持文本文件（txt / md / json / csv / 代码等），上传后文件内容会进入对话，多轮都记得；图片、PDF 等无法解析的文件会明确提示解析失败。
- **全文搜索**：点侧栏放大镜或按 Ctrl+K，搜索历史对话的标题、内容与思考过程。
- **导出对话**：设置 → 数据管理 → 导出所有历史对话，下载 JSON 文件。
- **会话管理**：新建、置顶、删除、重命名会话；重新生成、编辑消息。
- **主题**：浅色 / 深色 / 跟随系统。

## 配置自己的模型

三种方式，优先级从高到低，每个字段独立回退（比如只选了模型没填地址，地址就用网关的）：

1. **模型网关面板**（推荐）：点左下角齿轮，填接口地址（URL）和 API Key，点"获取模型列表"选模型，确定保存。保存后立即生效，不用刷新页面。配置只存在你自己的浏览器里。
2. **服务端配置文件**：复制 `local-config.example.json` 为 `local-config.json` 后填写，改完不用重启服务。
3. **内置模型网关**：上面两者都不填时使用，开箱即用。

接口需兼容 OpenAI `/chat/completions` 格式（绝大多数中转站与兼容接口都支持）。

## 架构

```
浏览器（对话界面，原生 HTTP + SSE）
    │  /api/v0/*（同源请求，只连本机）
    ▼
serve.py（纯 Python 标准库，零依赖）
    │  静态文件 + 会话存储 + 聊天桥接 + 搜索工具 + 文件解析 + 导出
    ▼
模型接口（面板配置 / local-config.json / 内置模型网关）
```

- `serve.py` —— 本地后端：静态服务、会话持久化、DeepSeek SSE 协议与 OpenAI 流式协议的双向翻译、系统人设、深度思考开关（含非推理模型的模拟思考）、智能搜索工具循环（含搜索卡片与引用角标）、文件上传、历史导出。
- `guard.js` —— 前端防护：拦截对外网原生接口的请求；隐藏本地版无意义的原生入口（下载应用、分享、注销账号等）；只拦截官方域名外链，模型回复里的普通外链可正常打开。
- `enhance.js` —— 模型网关面板（左下角齿轮）。
- `index.html` —— 入口页（内置本地登录态，无需登录）。
- `static/` —— 界面静态资源。

## 说明

- 浏览器本身只连接本机后端，不直连任何外部接口，因此不会出现"服务器繁忙 / 网络繁忙 / 服务器不可用"这类由官方接口故障引起的错误。
- 内置模型网关的默认配置以混淆形式存储在代码中（防一眼看穿，不是加密）。请不要把有余额的重要 Key 写进代码；自己的 Key 请用模型网关面板或 `local-config.json` 配置。
- 系统人设、搜索工具定义都只在后端，页面源码和浏览器存储里找不到，改不了。
- 不同模型对系统人设的服从程度不同：有的模型有自己固化的身份设定，不接受自定义身份；有的模型不支持工具调用（此时智能搜索自动退回普通对话）。人设与工具是否生效，取决于所用模型本身。
- 本项目界面基于 DeepSeek 官方网页版 UI 的静态资源，仅供学习交流使用。
